# セッション記録

意味のある AI 作業ごとに、簡潔な `YYYY-MM-DD-short-topic.md` を1つ追加する。terminal transcript ではなく結果を記録し、同日の名前は重複しないよう suffix を付ける。

```markdown
# Session: topic

## Request（依頼）
## Investigation（調査）
## Changes（変更）
## Files changed（変更ファイル）
## Validation（検証）
## Result（結果）
## Remaining issues（残件）
```

secret、credential、生の環境変数 dump、不要な command output は含めない。
