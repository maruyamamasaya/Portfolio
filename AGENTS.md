# AGENTS Instructions

## Scope
These instructions apply to the entire repository.

## Testing and Linting
- Run `npm test` and `npm run lint` before committing any code changes.
- For documentation or comment-only changes, tests and linting are not required.

## Coding Style
- Use TypeScript and React conventions with ESLint and Prettier configs.
- Reference existing images in `public/` or `data/`; do not generate new images or commit binaries.

## Git
- Commit directly to the default branch without creating new branches.
- Write clear commit messages in Japanese.
- Ensure the working tree is clean after each commit.

## Pull Requests
- Summarize code changes and include test and lint results in the PR description.
