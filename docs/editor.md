# 開発者向け記事編集ページ

`/developer_edit` では Markdown 形式の記事をブラウザ上で作成・編集できます。基本的な使い方と主な機能をまとめます。

## 主な機能

- **Markdown プレビュー切り替え** - 編集画面とプレビュー画面をボタンで切り替えられます。プレビューでは Markdown を HTML に変換した内容を即時反映します。
- **新規記事作成** - ファイル名とカテゴリーを指定して空の Markdown ファイルを生成し、そのまま編集画面へ遷移します。
- **画像アップロード** - 画像をドラッグ＆ドロップまたはファイル選択でアップロード可能です。`/images/` 配下に保存され、アップロード後は Markdown 本文へ画像リンクを自動挿入します。
- **フロントマター自動補完** - 新規作成時には `date` と `updated` が現在の日付で自動入力されます。
- **カテゴリ・タグの選択支援** - カテゴリーはプルダウンから選択、タグは既存タグ候補を表示しつつ、新しいタグも入力できます。

これらの機能により、コードエディタを開かなくても記事の投稿・更新が行えます。
