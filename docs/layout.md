# レイアウト向けの Tailwind クラス

記事ページなどでよく使うコンテナ関連のクラスの説明です。

| クラス | 内容 |
| --- | --- |
| `mx-auto` | 中央寄せ |
| `max-w-screen-md` | 最大幅を 768px に制限（一般的な読みやすいブログ幅） |
| `px-4` | 左右に 1rem（16px）のパディング |
| `sm:px-6 md:px-8` | ブレイクポイントごとに段階的に余白を広げる |

💡 **補足**  
`max-w-3xl`（768px）や `max-w-2xl`（640px）もブログや記事向けでよく使われます。  
`px` は 4～6 が読みやすさと視認性のバランスが良いです。
