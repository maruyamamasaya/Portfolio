# 記事本体サンプル

この記事では、ブログ記事の基本構造を確認します。投稿日や更新日、カテゴリやタグの使い方、見出し、コードブロック、画像、引用などをまとめました。

## 見出しレベル2

本文は見出しごとにまとめると読みやすくなります。

### 見出しレベル3

Markdown では `###` を使ってレベル 3 の見出しを表現します。

以下はコードブロックの例です。

```ts
function hello(name: string): string {
  return `Hello, ${name}!`;
}
```

画像は次のように埋め込みます。

![サンプル画像](/image/sample-article.png)

> これは引用ブロックです。引用したい文章をこの形式で記述します。

#### 見出しレベル4

h4 見出しでセクションをさらに細分化できます。

##### 見出しレベル5

より詳細な見出しには h5 を使います。

###### 見出しレベル6

ここまで細かい見出しを使うケースは少ないですが、Markdown では h6 も利用できます。

以下は別のコード例です。

```python
def add(a, b):
    return a + b
```

表形式の情報は次のようにまとめられます。

| 見出し | 内容 |
|------|------|
| A | aについて |
| B | bについて |
